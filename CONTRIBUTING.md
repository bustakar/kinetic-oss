# Contributing

Thanks for helping improve Kinetic.

## Issues

Use GitHub Issues for reproducible bugs and focused feature requests. For security vulnerabilities,
follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## Pull requests

1. Fork the repository and create a focused branch from `main`.
2. Install Node.js 24+ and pnpm 11+.
3. Copy `.env.example` to `.env.local` and select a personal Convex deployment.
4. Make the smallest coherent change and add focused tests when behavior changes.
5. Run `pnpm check`.
6. Open a pull request explaining the problem and solution.
