# Security Policy

## Supported versions

Security fixes are applied to `main` and the most recent tagged release. Older releases are not
supported.

## Reporting a vulnerability

Please report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/bustakar/kinetic-oss/security/advisories/new).
Do not open a public issue.

Include the affected component, reproduction steps, impact, and any suggested mitigation. Please
allow reasonable time for investigation before disclosing the issue publicly.
